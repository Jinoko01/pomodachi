# 음성 연결과 오디오 재생

## 연결과 자원 정리

- 음성 연결은 `@discordjs/voice`의 `joinVoiceChannel`로 만들고, 재생은 연결에 구독시킨 `AudioPlayer`로 처리한다.
- `/뽀모도로 중지`에서는 예약된 타이머 해제(`clearTimeout`), 플레이어 정지, 음성 연결 해제(`connection.destroy()`), 상태 Map 항목 삭제를 수행한다.
- 휴식 종료 후 자동 종료 경로에서는 음성 연결 해제와 상태 Map 항목 삭제를 수행하며, 플레이어는 별도로 정지하지 않는다.
- 새 종료 경로를 추가할 때는 `/뽀모도로 중지`의 정리 순서와 대상을 기준으로 한다.
- `setTimeout`으로 예약한 작업은 모두 해당 사용자의 타이머 상태에 기록해 중지 시 함께 해제할 수 있게 한다.
- 봇이 음성 채널에서 강제로 나가거나 연결이 끊기는 경우 남은 타이머와 상태가 정리되는지 검토한다.

## 플레이어와 이벤트

- 플레이어와 연결의 `error` 이벤트를 처리해 재생 오류로 프로세스가 중단되지 않게 한다.
- `AudioPlayerStatus.Idle` 등 이벤트 리스너는 플레이어 생성 시 한 번만 등록한다. 재생할 때마다 리스너를 추가로 등록하지 않는다.
- 배경음 반복 재생은 집중 시간에만 이루어져야 하며, 휴식 전환 시 반복이 멈추고 알림음이 재생되어야 한다.

## 오디오 파일

- 배경음은 `background-sound/`, 알림음은 `notify-sound/`의 `.mp3` 파일만 사용한다. 새 오디오는 코드 수정 없이 폴더에 파일을 추가하면 인식되는 구조를 유지한다.
- 재생 전에 파일 존재 여부를 확인한다. 배경음 파일이 없거나 집중 종료 시 알림음 파일이 없으면 경고를 보내고, 휴식 종료 시 알림음 파일이 없으면 안내 없이 재생을 건너뛴다.
- 기본 알림음 파일명(`기본알림음.mp3`)은 코드의 기본값과 일치해야 한다. 파일명을 바꾸면 코드와 문서를 함께 수정한다.
- 오디오 파일을 추가·삭제·이름 변경하려면 먼저 확인을 요청한다.

## 음성 관련 의존성

- `ffmpeg-static`, `libsodium-wrappers`, `@snazzah/davey`는 코드에서 직접 `import`하지 않아도 `@discordjs/voice`의 인코딩·암호화에 필요하므로 사용하지 않는 의존성으로 판단해 제거하지 않는다.
