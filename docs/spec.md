# 뽀모도로 봇 기능 명세서

> 이 문서는 `src/index.ts`의 **현재 구현**을 기준으로 정리한 명세다. 실제 Discord 환경에서 실행해 확인한 결과가 아니라 코드 분석 결과이며, 실행으로 확인이 필요한 항목은 `TBD` 또는 "확인 필요"로 표시한다.

## 1. 개요

- 디스코드 음성 채널에 접속해 집중·휴식 시간에 맞춰 알림음과 배경음을 재생하는 뽀모도로 타이머 봇이다.
- 모든 기능은 최상위 슬래시 커맨드 `/뽀모도로`의 서브커맨드로 제공된다.
- 타이머 1회 실행은 **집중 1회 → 휴식 1회**로 끝난다. 자동으로 다음 사이클을 반복하지 않는다.
- 타이머와 오디오 설정은 **사용자 단위**(`interaction.user.id`)로 관리한다.
- 음성 연결은 서버(길드)당 하나이므로 **한 서버에서는 한 사람의 타이머만** 진행할 수 있다.

## 2. 실행 환경과 초기화

| 항목 | 내용 |
|------|------|
| 런타임 | Node.js 20.11 이상, TypeScript(ESM) |
| 환경 변수 | `DISCORD_TOKEN` (필수). 없으면 시작 시 `Error`를 던지고 종료한다. |
| 게이트웨이 인텐트 | `Guilds`, `GuildVoiceStates` |
| 커맨드 등록 | `ready` 이벤트에서 `Routes.applicationCommands`로 **전역 등록**. 실패 시 `❌ 슬래시 커맨드 등록 오류` 로그만 남기고 봇은 계속 동작한다. |
| 오디오 폴더 | 프로젝트 루트의 `background-sound/`, `notify-sound/`. 시작 시 폴더가 없으면 생성한다. |

시작 로그:

```text
✅ <봇 태그> 봇이 성공적으로 로그인했습니다!
🔄 슬래시 커맨드 업데이트 중...
✅ 슬래시 커맨드가 성공적으로 등록되었습니다.
```

## 3. 커맨드 명세

### 3.1 서브커맨드 요약

| 서브커맨드 | 옵션 | 응답 공개 여부 |
|-----------|------|---------------|
| `/뽀모도로 시작` | `집중시간`(정수, 선택), `휴식시간`(정수, 선택) | 공개 (조건 미충족 안내는 ephemeral) |
| `/뽀모도로 배경음` | `파일명`(문자열, 필수, 자동완성) | 공개 (파일 없음 안내는 ephemeral) |
| `/뽀모도로 알림음` | `파일명`(문자열, 필수, 자동완성) | 공개 (파일 없음 안내는 ephemeral) |
| `/뽀모도로 목록` | 없음 | ephemeral |
| `/뽀모도로 중지` | 없음 | 공개 (타이머 없음 안내는 ephemeral) |
| `/뽀모도로 도움말` | 없음 | ephemeral |

### 3.2 `/뽀모도로 시작`

**옵션**

| 옵션 | 타입 | 필수 | 기본값 | 설명 |
|------|------|------|--------|------|
| `집중시간` | Integer | 아니오 | 25 | 집중 시간(분), 1~180 |
| `휴식시간` | Integer | 아니오 | 5 | 휴식 시간(분), 1~180 |

- 허용 범위는 `setMinValue(1)`/`setMaxValue(180)`으로 정의하며, 범위 밖 값은 Discord 클라이언트가 입력 단계에서 막는다.

**사전 조건 검사 (순서대로)**

1. 요청한 사용자의 타이머가 진행 중이면 거부한다. 휴식이 끝나 자동 종료를 기다리는 타이머(`ended: true`)는 진행 중으로 보지 않는다.
   - ephemeral: `⏳ 현재 뽀모도로 타이머가 이미 진행 중입니다! (중지하려면 `/뽀모도로 중지`를 입력하세요)`
2. 길드(캐시된 길드) 안이 아니거나 사용자가 음성 채널에 접속해 있지 않으면 거부한다.
   - ephemeral: `❌ 봇이 알림음을 재생하려면 먼저 음성 채널에 접속해 있어야 합니다.`
3. 같은 서버에서 다른 사용자의 타이머가 진행 중이면 거부한다(자동 종료 대기 중인 타이머는 제외).
   - ephemeral: `⚠️ 이 서버에서는 이미 <@사용자>님의 뽀모도로 타이머가 진행 중입니다. 봇은 한 서버에서 하나의 타이머만 진행할 수 있으니, 해당 타이머가 끝난 뒤 다시 시작해 주세요.` (멘션 알림 없음)

검사를 통과하면 자동 종료를 기다리던 본인 타이머와 같은 서버의 타이머를 먼저 정리한 뒤 시작한다.

**동작**

1. 사용자의 오디오 설정을 불러온다. 설정이 없으면 배경음 없음, 알림음 `기본알림음.mp3`.
2. 공개 메시지로 시작을 알린다.
   ```text
   🍅 **뽀모도로 타이머 시작!** 딴짓 금지, 집중해 보세요! (종료: <t:집중종료:R>)
   ⚙️ **설정**: 집중 N분 / 휴식 M분 [/ 배경음: 파일명] / 알림음: 파일명
   ```
3. 사용자가 접속한 음성 채널에 봇이 접속하고 `AudioPlayer`를 연결한다.
4. `activeTimers`에 사용자의 타이머 상태를 등록하고, 플레이어·연결의 `error` 이벤트와 연결 상태 이벤트를 등록한다([4.1 비정상 종료](#41-비정상-종료)).
5. 배경음이 설정되어 있으면:
   - 파일이 있으면 재생을 시작하고, 재생이 끝날 때(`Idle`)마다 **집중 시간 동안만** 반복 재생한다.
   - 파일이 없으면 채널에 `⚠️ (경고) `파일명` 파일을 찾을 수 없어 배경 음악 없이 진행합니다.`를 보내고 배경음 없이 진행한다.
6. 이후 흐름은 [4. 타이머 흐름](#4-타이머-흐름)을 따른다.

### 3.3 `/뽀모도로 배경음`

- `파일명`이 `없음` 또는 `무음`이면 배경음을 해제한다(`null`).
- 그 외에는 `.mp3`로 끝나지 않으면 `.mp3`를 붙인다.
- 파일명에 경로가 포함되어 있거나(`path.basename`과 다름) `background-sound/`에 파일이 없으면 저장하지 않는다.
  - ephemeral: `❌ 배경음 폴더에서 `파일명` 파일을 찾을 수 없습니다. `/뽀모도로 목록`으로 사용 가능한 파일을 확인해 주세요.`
- 자동완성: `없음`과 `background-sound/`의 `.mp3` 파일 중 입력값을 포함하는 항목(대소문자 무시, 최대 25개)을 제안한다.
- 파일이 설정 이후 삭제될 수 있으므로 타이머 시작 시에도 존재 여부를 다시 검사한다.
- 응답(공개, 멘션 알림 없음): `🎵 배경음이 **파일명**(으)로 설정되었습니다!` / 해제 시 `**없음(무음)**`

### 3.4 `/뽀모도로 알림음`

- `.mp3`로 끝나지 않으면 `.mp3`를 붙인다.
- 파일명에 경로가 포함되어 있거나 `notify-sound/`에 파일이 없으면 저장하지 않는다.
  - ephemeral: `❌ 알림음 폴더에서 `파일명` 파일을 찾을 수 없습니다. `/뽀모도로 목록`으로 사용 가능한 파일을 확인해 주세요.`
- 자동완성: `notify-sound/`의 `.mp3` 파일 중 입력값을 포함하는 항목(대소문자 무시, 최대 25개)을 제안한다.
- 알림음 재생 시점에도 존재 여부를 다시 검사한다.
- 알림음을 해제하는 값은 없다.
- 응답(공개, 멘션 알림 없음): `🔔 알림음이 **파일명**(으)로 설정되었습니다!`

### 3.5 `/뽀모도로 목록`

- `background-sound/`, `notify-sound/`에서 파일명이 `.mp3`로 끝나는 파일을 나열한다(대소문자 구분).
- 폴더에 파일이 없으면 `📂 파일이 없습니다.`, 폴더가 없으면 `📂 폴더가 없습니다.`를 표시한다.
- 응답(ephemeral):
  ```text
  🎵 **사용 가능한 오디오 목록:**

  **[배경음 (background-sound)]**
  - `파일.mp3`

  **[알림음 (notify-sound)]**
  - `파일.mp3`
  ```

### 3.6 `/뽀모도로 중지`

- 요청한 사용자의 타이머가 없으면 ephemeral: `❌ 현재 진행 중인 뽀모도로 타이머가 없습니다.`
- 타이머가 있으면 공통 정리 함수 `stopTimer`로 `activeTimers`에서 삭제 → 예약된 모든 `setTimeout` 해제 → 플레이어 정지 → 음성 연결 해제 순으로 정리한다.
- 응답(공개): `🛑 뽀모도로 타이머를 중지했습니다.`
- 다른 사용자의 타이머는 중지할 수 없다.

### 3.7 `/뽀모도로 도움말`

- `시작`, `배경음`, `알림음`, `목록`, `중지` 서브커맨드의 사용법을 ephemeral로 안내한다.

## 4. 타이머 흐름

```text
[시작] ──집중시간──▶ [휴식 전환] ──휴식시간──▶ [휴식 종료] ──60초──▶ [자동 종료]
  │                    │                        │                     │
  배경음 반복 재생      배경음 정지               알림음 재생           음성 연결 해제
                       알림음 재생               종료 안내 메시지      activeTimers 삭제
                       휴식 안내 메시지
```

| 시점 | 동작 | 채널 메시지(공개) |
|------|------|------------------|
| 집중 종료 | 배경음 반복 중단, 플레이어 정지 후 알림음 재생 | `🔔 <@사용자>님, 집중 시간이 지났습니다! 고생하셨어요.`<br>`지금부터 **푹 쉬고 오세요!** ☕ (휴식 종료: <t:휴식종료:R>)` |
| 집중 종료 시 알림음 파일 없음 | 알림음 재생 생략 | `⚠️ (경고) `파일명` 파일을 찾을 수 없습니다.` |
| 휴식 종료 | `ended: true` 표시, 알림음 재생 (파일 없으면 **안내 없이** 생략) | `⏰ <@사용자>님, 휴식 시간이 끝났습니다!`<br>`다시 집중할 시간입니다. (다시 시작하려면 `/뽀모도로 시작`을 입력하세요)` |
| 휴식 종료 60초 후 | `stopTimer`로 정리 | 없음 |

- 휴식 종료 후 60초 대기 중에도 `/뽀모도로 시작`을 실행하면 대기 중인 타이머를 즉시 정리하고 새 타이머를 시작한다.
- 채널 메시지는 커맨드를 실행한 텍스트 채널(`interaction.channel`)로 보낸다. 채널이 `null`이면 메시지를 보내지 않는다. 전송에 실패하면(권한 부족, 채널 삭제 등) 오류 로그만 남기고 타이머는 계속 진행한다.
- 모든 `setTimeout`(집중 종료, 휴식 종료, 자동 종료)은 사용자 타이머 상태의 `timeouts`에 기록되어 `/뽀모도로 중지` 시 함께 해제된다.

### 4.1 비정상 종료

| 상황 | 동작 | 채널 메시지(공개) |
|------|------|------------------|
| 20초 안에 음성 연결이 `Ready`가 되지 않음 | `stopTimer`로 정리 | `❌ <@사용자>님, 음성 채널에 접속하지 못해 뽀모도로 타이머를 종료했습니다. 봇에게 해당 음성 채널의 **연결**·**말하기** 권한이 있는지 확인한 뒤 다시 `/뽀모도로 시작`을 입력하세요.` |
| 연결 끊김(`Disconnected`) | 5초 안에 재연결(`Signalling`/`Connecting`)되지 않으면 연결 해제 | 아래 행 참고 |
| `stopTimer`를 거치지 않고 연결이 해제됨(강제 퇴장, 재연결 실패) | `stopTimer`로 정리 | `⚠️ <@사용자>님, 음성 연결이 끊겨 뽀모도로 타이머를 종료했습니다. 다시 시작하려면 `/뽀모도로 시작`을 입력하세요.` |
| 플레이어·연결 `error` 이벤트 | 오류 로그 | 없음 |
| 인터랙션 처리 중 예외 | 오류 로그 후 ephemeral 안내(`reply`, 이미 응답했으면 `followUp`) | `❌ 명령을 처리하는 중 오류가 발생했습니다. 잠시 후 다시 시도해 주세요.` (ephemeral) |

## 5. 상태 관리

| 상태 | 키 | 값 | 생성 | 삭제 |
|------|----|----|------|------|
| `activeTimers` | 사용자 ID | `TimerData` (`timeouts`, `connection`, `player`, `channel`, `ended`) | `/뽀모도로 시작` | `/뽀모도로 중지`, 휴식 종료 60초 후, 자동 종료 대기 중 재시작, 비정상 종료 |
| `userAudioSettings` | 사용자 ID | `AudioSettings` (`bgmName: string \| null`, `notifyName: string`) | `배경음`·`알림음` 설정 시 | 삭제 경로 없음 |

- 두 Map 모두 메모리에만 존재하므로 봇을 재시작하면 모든 타이머와 사용자 설정이 초기화된다.
- 사용자 설정 기본값은 `{ bgmName: null, notifyName: '기본알림음.mp3' }`이며 `배경음`, `알림음`, `시작` 세 곳에서 동일하게 사용한다.
- 설정은 봇이 실행 중인 동안 길드와 관계없이 사용자 단위로 유지된다.

## 6. 오디오 파일

- 배경음은 `background-sound/`, 알림음은 `notify-sound/`의 `.mp3` 파일을 사용한다. 폴더에 파일을 추가하면 코드 수정 없이 `목록`과 설정에서 사용할 수 있다.
- 현재 포함된 파일:

| 폴더 | 파일 |
|------|------|
| `background-sound/` | `Moonlight_ 월광_국악.mp3`, `녹턴 작품번호 9-2_국악.mp3` |
| `notify-sound/` | `기본알림음.mp3`(기본값), `자명종소리.mp3` |

## 7. 현재 구현의 제약과 확인 필요 사항

코드 분석으로 확인한 동작이며, 의도된 명세인지는 결정되지 않았다.

- **1사이클 고정**: 휴식이 끝나면 타이머가 종료된다. 다음 집중은 사용자가 `/뽀모도로 시작`을 다시 실행해야 한다.
- **서버당 타이머 1개**: 같은 서버에서는 한 사람만 타이머를 진행할 수 있다. 여러 사람이 함께 쓰는 방식(음성 채널 단위 그룹 타이머)은 이후 작업으로 남긴다.
- **설정 비영속**: 사용자 오디오 설정은 메모리에만 있어 봇을 재시작하면 초기화된다. 영속 저장소는 통계 기능 작업에서 함께 설계한다.
- **길드 외 사용**: `시작`만 길드 여부를 검사한다. 나머지 서브커맨드의 DM 사용 가능 여부는 TBD.
- **음성 채널 이동**: 타이머 시작 후 사용자가 다른 음성 채널로 이동해도 봇은 처음 채널에 머문다.
